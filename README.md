A simple, elegant expense tracker built entirely with **Vanilla JavaScript** — **No frameworks, no libraries, no dependencies!** It helps you track your income and expenses in real-time, with persistent storage and a beautiful, responsive UI.

## ✨ Features

### 📊 Balance Overview
- **Current Balance** — Live calculation of `Income - Expenses`
- **Total Income** — Sum of all income transactions
- **Total Expenses** — Sum of all expense transactions

### 💸 Transaction Management
- ➕ **Add Transactions** — Add income or expense with description and amount
- 🗑️ **Delete Individual** — Remove any transaction with a confirmation dialog
- 🧹 **Delete All** — Clear all transactions at once
- 📋 **Transaction Counter** — Shows total number of transactions

### 🔒 Data Persistence
- **LocalStorage Integration** — All data persists after page reload
- **No Backend Required** — Works completely offline

### 🎨 User Interface
- **Dark / Light Mode** — Toggle themes with preference saved in LocalStorage
- **Real-time Rendering** — UI updates instantly on every action
- **Fully Responsive** — Works perfectly on all screen sizes
- **Arabic RTL Support** — Fully optimized for Arabic users
- **Modern Styling** — Gradient balance card, smooth transitions, hover effects
